# Businitti — интернет-магазин украшений

Полнофункциональный e-commerce проект: основной сайт, админ-панель и backend. Сделан под реальный функционирующий магазин украшений ручной работы.

🔗 [businitti.ru](https://businitti.ru)

## Стек

**Frontend (основной сайт)** — React 18, TypeScript, Vite, React Router  
**Frontend (админка)** — React 18, TypeScript, Vite  
**Backend** — Node.js, Express, TypeScript ESM, Pino logging  
**База данных** — Google Sheets API 
**Хранилище медиа** — S3-совместимое 
**Платежи** — Робокасса  
**Email** — RuSender (транзакционные письма)  
**Деплой** — reg.ru VDS, nginx, pm2  

## Что умеет

### Покупателю
- Каталог с категориями, сортировкой, наличием в реальном времени  
- Корзина с расчётом доставки (СДЭК / Яндекс Маркет)  
- Оформление заказа → оплата через Робокассу → письмо с подтверждением  
- Письмо с трек-номером после отправки (со ссылкой на отслеживание)  

### Администратору
- Управление товарами и категориями: добавление, редактирование, drag&drop сортировка, мультикатегории
- Список заказов с фильтрами по статусу и поиском
- Контент: для редактирования всех медиа и статических текстов на гл сайте
- Workflow заказа: `pending_payment → new → shipped → cancelled/refunded`
- Ввод трек-номера и автоматическое письмо клиенту
- Статистика: выручка, средний чек, разбивка по статусам
- Ссылки: редактирование диплинков на сайте и в письмах
- Telegram бот: получение уведомлений о новых заказах в мессенджер 

## Архитектурные решения

- **Google Sheets вместо БД** — клиент работает с привычным интерфейсом таблиц, миграции происходят автоматически при старте
- **Источник истины — backend** — цены товаров и доставки пересчитываются на сервере при создании заказа (клиенту нельзя подделать)
- **Идемпотентные webhooks** — Result URL Робокассы безопасен к повторам (статус-чек перед обновлением)
- **Асинхронный ответ webhook'у** — Робокассе отвечаем сразу, side-effects (списание stock, email) идут в фоне
- **Server-side фискализация** — чек с `tax: "none"` для самозанятых формируется автоматически
- **Rate limiting** — защита `/api/auth/login` и публичной формы заказа от brute force/спама
- **Security headers** — `helmet`, `trust proxy` для корректного IP за nginx
- **SEO** — базовое индексирование сайта, Яндекс Метрика / Гугл Аналитика
